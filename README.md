Proyecto final — Equipo 5

Sistema de Gestión de Torneos de E-Sports

Proyecto final de Programación Orientada a Objetos desarrollado mediante HTML, CSS y JavaScript.

Proyecto integrado

La versión final del sistema se encuentra en la carpeta Proyecto_Equipo5.

Esta carpeta contiene todos los archivos necesarios para ejecutar la página web, así como el diagrama de clases y el diagrama de casos de uso.

Funcionalidades

Registro y validación de jugadores.

Clasificación por roles de estrategia y acción.

Cálculo individual de MMR.

Creación de escuadras de máximo cinco jugadores.

Cálculo del MMR promedio.

Implementación de encapsulamiento, herencia y polimorfismo.

Aportaciones individuales

Las demás carpetas del repositorio contienen las aportaciones individuales de los integrantes del equipo y se conservan como evidencia del desarrollo colaborativo.
